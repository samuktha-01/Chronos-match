# Cython Matching Engine Build Guide

## Overview

ChronosMatch provides an optional Cython-accelerated matching engine module (`chronosmatch.cython_engine`) designed to maximize order matching throughput and minimize matching latency through C-level loops and data structures.

The Cython implementation is decoupled into three layers:
1. **Cython Definition & C Source**:
   - `src/chronosmatch/_cython_engine.pyx`: High-performance Cython source file with C-typed variables and methods.
   - `src/chronosmatch/_cython_engine.c`: Transpiled C source generated by Cython 3.3.0.
2. **Build Configuration**:
   - `setup.py`: Standard setuptools configuration compiling `_cython_engine` with native optimization flags (`/O2 /fp:fast` on Windows MSVC, `-O3 -march=native` on GCC/Clang).
3. **Dual-Mode Import & Fallback Facade**:
   - `src/chronosmatch/cython_engine.py`: Attempts to load the compiled native binary (`_cython_engine.pyd` on Windows / `.so` on POSIX). If absent, it automatically activates the pure-Python reference fallback with 100% behavioral equivalence.

## Windows Prerequisites & Build Instructions

### Prerequisites

To compile the C extension into a Windows `.pyd` shared library, one of the following C compilers must be installed:

1. **Microsoft C++ Build Tools** (Recommended for Windows):
   - Download: [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
   - Workload to select: **Desktop development with C++** (includes MSVC `cl.exe` v143+ and Windows 10/11 SDK).
2. **MinGW-w64 / GCC**:
   - Alternatively, install `mingw-w64` (e.g. via MSYS2 or `winget install MSYS2.MSYS2`).

### Build Commands

From the project root (`Chronos-match/`):

```powershell
# 1. Compile in-place
python setup.py build_ext --inplace

# 2. Or install in editable development mode
pip install -e .
```

### Verification Command

Verify that the compiled extension is active:

```powershell
python -c "from chronosmatch import is_cython_compiled, get_compilation_status; print(get_compilation_status())"
```

Expected output when compiled:
```json
{"is_compiled": true, "c_source_exists": true, "pyx_source_exists": true, "build_limitation": null}
```
